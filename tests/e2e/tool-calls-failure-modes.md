# 通用工具调用：失败方式与验收

先列出失败方式，再从实际 CLI、后台和 Bridge 入口验证；不操作日常配置或真实账号。记录到忽略的 `artifacts/e2e/`。

| 场景 | 预期 |
| --- | --- |
| 缺少命令参数或 `--stdin` | 退出 2，JSON 错误，不启动后台 |
| stdin 损坏、非对象、超过 8 MiB | 退出 2，不回显输入，不派发工具 |
| 连接不存在、已断开、Gateway 暂停、认证失效 | 退出 1，不按显示名寻找替代连接 |
| 指定工具不存在或被筛选 | 退出 1，不执行上游工具 |
| 工具在后续分页中 | 完整发现后按精确工具名选择 |
| 重复工具名、循环游标或超量分页 | 明确失败，不选择不确定工具或无限循环 |
| 嵌套对象、数组、布尔值、整数、空值 | 依照 Schema 验证并原样传递，不强制转成字符串 |
| 必需项、类型、枚举、边界、组合和本地引用不匹配 | 退出 2，派发前失败；错误只含 Schema 位置，不回显参数值 |
| 上游 Schema 无效或外部引用不可用 | 退出 1，不读取文件或联网获取引用，不跳过校验 |
| Schema 摘要与调用方固定摘要不一致 | 退出 1，提示重新发现或生成，不派发 |
| 发现期间连接修订发生变化 | 退出 1，不将旧 Schema 校验结果用于另一修订 |
| 上游 `isError` 或 MCP RPC 错误 | 退出 1，保留 MCP 结果供调用方判断 |
| 调用超时或通信中断 | 退出 1，提示结果需核对；不自动重放 |
| 新 CLI 连接仍在运行的旧后台 | 退出 1，提示使用相同构建重启；不发送旧后台不支持的工具操作 |
| CLI 与原生 Bridge 的有效调用 | 同一托管连接、工具名、参数和结果一致 |
| 凭据更新、OAuth 刷新或后台恢复 | 继续复用现有管理核心、凭据库和共享会话 |

新增契约：`connections tools ID --tool TOOL` 返回指定工具 Schema 与摘要；`call ID TOOL --stdin [--schema-hash HASH]` 从 stdin 接收工具参数对象。CLI 帮助和 `schema` 离线可用。现有 `connections tools ID` 和 `mcp request` 保留原有语义。
