# 支持范围

本页说明产品能力和限制。客户端配置及操作范围见 [Agent 兼容矩阵](agent-discovery.md)，命令契约以安装版本的 `mcplink schema` 为准。

## 平台

| 平台 | 分发与检查范围 |
| --- | --- |
| macOS Apple Silicon | 桌面应用、DMG、App ZIP 和独立 CLI；CI 覆盖构建、配置事务、界面、后台及安装包检查。默认预览包为 ad-hoc 签名。 |
| Windows x64 | 桌面应用、NSIS 安装包和独立 CLI；CI 覆盖构建、配置事务、后台及进程清理。默认安装包未签名。 |
| Linux / Intel Mac | 暂无已验收的安装包。 |

签名与公证配置见[发布指南](release.md)。CI 和验收工件对应具体源码提交；自动化检查不代表所有客户端版本、系统授权或业务账号均兼容。

## 配置管理

- 客户端安装状态、配置来源和支持操作分别检查；目录残留不代表客户端已安装。
- 用户来源按支持的路径盘点，项目与 profile 来源显式添加，不递归扫描任意项目目录。
- 原生文件适配复用预览、哈希冲突检查、备份、原子写入和条目恢复；需要在客户端确认的配置不产生托管绑定。
- TOML、YAML、JSON、JSONC 和 JSON5 按客户端格式处理，保留未涉及的配置。TOML inline table 可盘点，暂不直接编辑。
- 插件、托管策略及其他只读来源保留权限；符号链接可读，写入须选择真实文件。
- 客户端未提供等价字段时，拒绝丢失限制的转换；可以等价执行的限制由共享网关维护。
- 不读取原生登录缓存或 `.env`，不代替客户端授予审批、信任或账号权限。

STDIO 命令需要能在桌面实际继承的运行环境中找到，推荐绝对路径。应用不会自动加载交互 Shell 的初始化文件。账号标签由用户维护，不代表上游确认的身份或组织。

## MCP 协议

支持 STDIO、Streamable HTTP 及普通 tools、resources、prompts 请求。Streamable HTTP 可处理 JSON 和 SSE 响应，不支持旧 HTTP+SSE endpoint。当前使用 legacy `initialize` 流程，不宣告尚未实现的 tasks、sampling、elicitation、订阅或完整取消传播。

共享入口保留上游工具名称和 Schema；客户端可能自行正规化名称。会产生冲突的接入名在写入前拒绝。工具调用失败、超时或通信中断后不自动重发，调用方需核对执行结果及可能产生的业务副作用。

## 认证

支持按上游契约配置 HTTP Token 和 OAuth。令牌原样保存，不自动添加 Bearer；OAuth 支持 PKCE、发现、动态注册或预注册应用、客户端机密、显式 scope、loopback 回调和刷新轮换。认证与业务权限由上游决定。

业务 API 的 OAuth、MCP 入口的 Token 和客户端自身登录不能互相替代。自动刷新需要上游提供可刷新的授权；手工更新凭据不视为自动刷新。部分服务在 MCP 成功响应中封装业务错误，调用方仍需检查其结果契约。

系统凭据库首次访问可能要求系统确认。完整定义、凭据和配置备份按敏感数据处理；共享原生条目只保存本地入口与连接引用，直连配置可能包含明文凭据。

## 加载与恢复

文件写入或配置生成成功后，客户端仍需重新加载并完成实际工具调用。界面不会将写入状态当作已获信任或业务调用成功。

操作按条目恢复；同一条目有后续修改时拒绝覆盖，无关条目的修改保留。直连在托管定义更新后需重新预览同步，共享连接复用更新后的托管授权。程序移动后需从新位置重新生成共享入口。

后台可按需启动，暂停状态持久化。关闭窗口、退出界面和完整退出的行为分别见 [macOS](macos-background.md) 与 [Windows](windows-background.md)。
