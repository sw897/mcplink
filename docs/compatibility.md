# 支持范围

本页说明当前构建的能力和限制。产品目标见[产品定位](product.md)，客户端配置及操作范围见 [Agent 兼容矩阵](agent-discovery.md)，命令契约以安装版本的 `mcplink schema` 为准。

## 核心能力状态

- **多 MCP Server 统一接入**：支持单个 `mcplink` 条目提供入口选中的多个上游，聚合工具、资源与提示词，处理命名空间、分页及故障诊断。
- **MCP 转 CLI**：支持服务或聚合入口中的工具调用、CLI 生成、JSON 输入输出、参数校验及契约检查。生成物依赖本机 mcplink 运行时和托管连接。
- **认证复用**：单服务入口、聚合入口和 CLI 共用成员连接的托管授权；原生直连保留为可选方式，其认证由客户端维护。

## 平台

| 平台 | 分发与检查范围 |
| --- | --- |
| macOS Apple Silicon | 桌面应用、DMG、App ZIP 和独立 CLI；CI 覆盖构建、配置事务、界面、后台及安装包检查。默认预览包为 ad-hoc 签名。 |
| Windows x64 | 桌面应用、NSIS 安装包和独立 CLI；CI 覆盖构建、配置事务、后台及进程清理。默认安装包未签名。 |
| Linux / Intel Mac | 暂无已验收的安装包。 |

签名与公证配置见[发布指南](release.md)。CI 和验收工件对应具体源码提交；自动化检查不代表所有客户端版本、系统授权或业务账号均兼容。

## 配置管理

- 客户端安装状态、配置来源和支持操作分别检查；目录残留不代表客户端已安装。
- 用户来源按支持的路径盘点，项目与 profile 来源显式添加，不递归扫描任意项目目录。
- 原生文件适配复用预览、哈希冲突检查、备份、原子写入和条目恢复；需要在客户端确认的配置不产生托管绑定。
- TOML、YAML、JSON、JSONC 和 JSON5 按客户端格式处理，保留未涉及的配置。TOML inline table 可盘点，暂不直接编辑。
- 插件、托管策略及其他只读来源保留权限；符号链接可读，写入须选择真实文件。
- 客户端未提供等价字段时，拒绝丢失限制的转换；可以等价执行的限制由共享网关维护。
- 不读取原生登录缓存或 `.env`，不代替客户端授予审批、信任或账号权限。

STDIO 命令需要能在桌面实际继承的运行环境中找到，推荐绝对路径。应用不会自动加载交互 Shell 的初始化文件。账号标签由用户维护，不代表上游确认的身份或组织。

## MCP 协议

支持 STDIO、Streamable HTTP 及普通 tools、resources、prompts 请求。Streamable HTTP 可处理 JSON 和 SSE 响应，不支持旧 HTTP+SSE endpoint。当前使用 legacy `initialize` 流程，不宣告尚未实现的 tasks、sampling、elicitation、订阅或完整取消传播。

单服务入口保留上游工具名称和 Schema。聚合入口的工具及提示名称使用稳定服务前缀，过长或特殊名称使用确定性摘要别名；资源 URI 与模板增加 `mcplink://命名空间/` 前缀，工具及提示结果中的资源引用同步转换。客户端可能自行正规化显示名称。会产生冲突的原生接入名在写入前拒绝。

每个入口最多选择 64 项服务；每个上游清单最多 100 页、10000 项，聚合清单最多 10000 项、4 MiB，每页 100 项。各上游清单并行发现，单个上游发现限时 10 秒；故障在 MCP 清单的 `_meta.mcplink.upstreamErrors` 返回，健康服务仍可使用。

同一次分页使用固定的内存快照，后续页不重新发现上游，避免动态描述或列表顺序变化中断客户端加载。快照最长保留 5 分钟，最多 32 份，序列化清单预算 16 MiB；过期或被淘汰后需要从第一页刷新。入口选择、成员定义或认证变更会使旧游标失效，新第一页重新发现当前上游。后续页保持原快照；上游清单通知不会打断正在进行的分页。新的第一页读取最新清单。

单服务与聚合 Bridge 对所支持的 tools、resources、prompts 宣告 `listChanged`。后台接收上游通知，Bridge 每 2 秒比较所属入口的本地清单版本并发送对应通知；入口范围、成员定义、认证或暂停变化也会触发通知。正常轮询复用已认证的本地通信客户端，不访问凭据库、不发现上游清单、不执行工具，也不启动已停止的后台；实际请求恢复后台后重新接续通知。Bridge 断开时结束监听。官方 Pi MCP 运行时已覆盖自动刷新；不能处理通知的客户端仍需重新加载 MCP。手动 `gateway refresh ID` 只通知指定入口；对服务连接执行时，其引用入口一起更新。

入口成员的 `includeTools` 是可选的精确工具名白名单，与服务全局工具策略取交集；省略或 null 沿用服务范围，空数组不开放工具。保存接口中省略该成员的工具策略会保留已存值。工具发现、Bridge 调用、通用 CLI 与生成 CLI 均执行入口策略；资源与提示词不受此工具白名单影响。入口筛选是同一用户的调用视图，不是对有本机管理权限的程序建立安全隔离。

工具调用失败、超时或通信中断后不自动重发，调用方需核对执行结果及可能产生的业务副作用。

## 认证

支持按上游契约配置 HTTP Token 和 OAuth。令牌原样保存，不自动添加 Bearer；OAuth 支持 PKCE、发现、动态注册或预注册应用、客户端机密、显式 scope、loopback 回调和刷新轮换。认证与业务权限由上游决定。

业务 API 的 OAuth、MCP 入口的 Token 和客户端自身登录不能互相替代。自动刷新需要上游提供可刷新的授权；手工更新凭据不视为自动刷新。部分服务在 MCP 成功响应中封装业务错误，调用方仍需检查其结果契约。

系统凭据库首次访问可能要求系统确认。完整定义、凭据和配置备份按敏感数据处理；共享原生条目只保存本地入口与连接引用，直连配置可能包含明文凭据。

认证复用以同一本机数据目录内的托管连接 ID 为准。同一地址使用不同账号时分别创建连接，入口不按名称猜测账号；不同数据目录或设备不自动共享登录态。更改账号权限、上游撤销授权或无法刷新时需重新授权。

## 加载与恢复

文件写入或配置生成成功后，客户端仍需重新加载并完成实际工具调用。界面不会将写入状态当作已获信任或业务调用成功。

操作按条目恢复；同一条目有后续修改时拒绝覆盖，无关条目的修改保留。直连在托管定义更新后需重新预览同步，共享连接复用更新后的托管授权。程序移动后需从新位置重新生成共享入口。

后台可按需启动，暂停状态持久化。关闭窗口、退出界面和完整退出的行为分别见 [macOS](macos-background.md) 与 [Windows](windows-background.md)。
