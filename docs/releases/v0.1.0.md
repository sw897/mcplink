# mcplink v0.1.0 · Preview / 预览版

A local desktop MCP (Model Context Protocol) manager and gateway for Codex and Hermes, with read-only discovery and import from Claude Code. Built with Tauri, React, TypeScript, and Rust; the desktop app and JSON CLI share one management core.

## Highlights

- Discover and import existing MCP connections; choose direct access or a shared local gateway per service.
- Preview configuration edits, reject concurrent changes, and restore individual operations while preserving unrelated settings.
- Keep managed secrets in the system credential store; reuse updated credentials through shared connections.
- Manage connections from the desktop or JSON CLI and install the bundled mcplink management Skill.
- Support STDIO and Streamable HTTP; inspect tools, resources, and prompts through the existing MCP request interface.
- Read Claude Code user configuration and enabled user plugins without changing those source files.

Copy the macOS app to `/Applications` before configuring shared connections, or run the Windows installer. Keep the standalone CLI and its license files in a permanent location. Agent configuration uses the selected program's absolute path; after moving it, preview and apply the connection again.

This is a **pre-release**. macOS packages are **ad-hoc signed, without Developer ID or notarization**. The Windows installer is **unsigned**. Operating-system security prompts are expected; review [Apple's guidance](https://support.apple.com/en-us/102445) if macOS blocks the preview.

## Validation and limits

- macOS Apple Silicon and Windows x64: CI build, static checks, and 44 isolated scenarios per platform (24 core, 12 named CLI, 8 Claude sources).
- macOS: local desktop flow, DMG/app/CLI archive checks, and 5 installed-app scenarios covering shared credentials, background recovery, and application relocation.
- Windows: NSIS payload, bundled licenses, and build-machine path checks. Desktop interaction has not been accepted on a physical Windows installation.
- Synthetic MCP/OAuth services and fixture credentials are used for isolated acceptance. New-user Keychain access and downloaded-app Gatekeeper acceptance remain unverified.
- Configuration writes support Codex and Hermes. Claude Code sources are read-only. No automatic updater, Intel Mac/Linux packages, or general-purpose CLI generator is included.

Reload MCP or start a new agent session after applying changes. File writes alone do not prove that an active agent has loaded a connection. See [compatibility](https://github.com/sw897/mcplink/blob/v0.1.0/docs/compatibility.md), [CLI usage](https://github.com/sw897/mcplink/blob/v0.1.0/docs/agent-cli.md), and the [release guide](https://github.com/sw897/mcplink/blob/v0.1.0/docs/release.md).
