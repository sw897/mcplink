# mcplink 0.1.0

macOS Apple Silicon 首版候选。桌面和 CLI 共用管理核心，可盘点、导入并管理 Codex/Hermes 的 MCP 配置，按服务选择直连或共享后台。

- 变更先预览，保留无关设置；支持批量接入、停用、移除和逐条恢复。
- 托管凭据保存在系统凭据库。腾讯文档通过手工 Token 更新共享授权；标准 OAuth 刷新已用合成上游验证。
- 内置管理 Skill 可以独立安装到 Agent；业务 Skill 的版本与分发继续使用 Git。
- Claude Code 用户与已启用用户插件来源可只读盘点和导入，原配置继续由 Claude Code/插件维护。

安装时将 DMG 内的 `mcplink.app` 复制到固定位置后再配置共享入口。从终端使用包内 CLI：

```sh
/Applications/mcplink.app/Contents/MacOS/mcplink schema
```

应用移动后，需要从新位置重新预览并应用共享配置，然后重新加载 Agent。替换安装前退出桌面，并停止旧后台；保留本地数据和系统凭据。首版不提供自动更新或整库迁移。

本地候选包使用 ad-hoc 签名，不能视为已通过 Developer ID、公证或下载后的 Gatekeeper 验收。正式签名工作流要求签名与公证校验通过，产物仅写入 Release 草稿。

Windows、Intel Mac、Linux 和全新 macOS 账号尚未实机验收。完整协议和账号限制见 [兼容说明](../compatibility.md)，构建和发布步骤见 [发布指南](../release.md)。
